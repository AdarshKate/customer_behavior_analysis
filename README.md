# Customer Shopping Behavior Analysis

## 📌 Overview

This project analyzes customer shopping behavior to identify purchasing patterns, product preferences, and sales trends. It uses Python for data cleaning and Exploratory Data Analysis (EDA), PostgreSQL for SQL-based analysis, and Power BI to create an interactive dashboard.

The goal is to transform raw customer shopping data into meaningful insights that support data-driven business decisions.

## 🚀 How to Run

### Prerequisites

Install or set up the following tools:

- Python 3.x
- Jupyter Notebook
- PostgreSQL
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/customer_shopping_behavior_analysis.git
cd customer_shopping_behavior_analysis
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### Step 3: Run the Python Analysis

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the project notebook and run the cells to load, clean, and analyze the dataset.

### Step 4: Set Up PostgreSQL

- Create a PostgreSQL database.
- Import the cleaned dataset into a table.
- Update the database connection settings in your scripts.
- Execute the SQL queries included in the project.

### Step 5: Open the Power BI Dashboard

- Open the `.pbix` file using Power BI Desktop.
- Configure the data source if required.
- Refresh the data to view the dashboard.
